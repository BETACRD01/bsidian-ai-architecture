# Skill Routing Map

This map connects the skill areas without merging their responsibilities.

## Routing Rules
- Start from the project dashboard that matches the task.
- Use only one primary skill area at a time.
- Add a support skill only when the task explicitly needs it.
- Keep notes, logs, and outputs inside the primary project folder.
- Use cross-project links for navigation and collaboration, not for mixing content.
- Use [[references/checklist|Global Checklist]] only as shared validation, never as a project owner.

## Primary Skill Areas
- [[Marketing_Project/00_Dashboard/Marketing_Overview|Marketing]]: campaigns, funnels, CRO, SEO, ads, email, launches, pricing, and growth strategy.
- [[Stop_Slop_Project/00_Dashboard/StopSlop_Overview|Stop Slop]]: copy cleanup, clarity, tone, structure, and language quality.
- [[UI_UX_Pro_Max_Project/00_Dashboard/UI_UX_Overview|UI/UX Pro Max]]: interface design, UX reasoning, visual systems, product flows, and design data.
- [[Remotion_Project/00_Dashboard/Remotion_Overview|Remotion]]: programmatic videos, motion assets, rendering, and short-form video systems.
- [[Context_Engineering_Project/00_Dashboard/Context_Overview|Context Engineering]]: prompts, memory, RAG, agents, cognitive tools, protocols, and evaluation.

## Boundaries
- Marketing decides market strategy, not UI implementation details.
- UI/UX decides interface structure, not campaign strategy.
- Stop Slop improves language, not product architecture.
- Remotion creates video systems, not written campaign strategy.
- Context Engineering designs agent and prompt systems, not final business positioning by itself.
