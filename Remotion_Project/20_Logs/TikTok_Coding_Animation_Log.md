# Proyecto: TikTok Coding Animation

Animación corta de 5 segundos para TikTok (formato 9:16).

## Archivos
- Componente: `[[CodingAnimation.tsx]]`
- Root: `[[Root.tsx]]`

## Renderizado
Ejecuta el siguiente comando en tu terminal para generar el video:

```bash
npx remotion render src/index.ts CodingAnimation out/coding-tiktok.mp4
```

## Notas
- Formato: 1080x1920 (TikTok)
- Duración: 150 frames (5 segundos a 30 fps)
- Tema: Coding typewriter effect.
